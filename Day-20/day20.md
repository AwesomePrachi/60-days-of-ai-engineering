# Day 20 – AI Face Puzzle Game

## Challenge

For Day 20 of the 60 Day Claude Challenge, I built an AI Face Puzzle Game using Claude AI.

The application captures a photo using the device camera and transforms it into an interactive puzzle game. Players can select different difficulty levels, solve the puzzle, track their progress, and compete against their best scores.

## What I Built

A browser-based Face Puzzle Game with:

* Webcam Integration
* Dynamic Puzzle Generation
* Drag-and-Drop Puzzle Mechanics
* Mobile Touch Support
* Timer & Move Tracking
* Hint System
* Dark Mode
* Confetti Celebration
* Local Storage Leaderboard
* Responsive UI

## Features

### Camera Integration

* Access device webcam
* Capture photos directly in the browser
* Retake photos anytime

### Puzzle System

* Easy (3×3)
* Medium (4×4)
* Hard (5×5)

### Gameplay Features

* Live Timer
* Move Counter
* Progress Tracking
* Correct Tile Detection
* Hint System
* Shuffle Again Option

### User Experience

* Glassmorphism Design
* Dark Mode
* Responsive Layout
* Animated Interactions
* Celebration Effects

### Data Persistence

* Leaderboard stored using localStorage
* Best scores saved across sessions

## What I Learned

This project was a great exercise in browser APIs, image processing, drag-and-drop functionality, local storage, and game development—all within a single HTML file.

I also learned how AI can accelerate the development process by generating complete applications that combine functionality, design, and user experience.
