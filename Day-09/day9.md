# Day 9 — Claude Artifacts: Build & Enhance an AI Nutrition Analytics App

## Challenge Objective

The goal of Day 9 was to learn iterative AI application development using Claude Artifacts.

Rather than generating a large application in a single prompt, the challenge focused on building an MVP first and then progressively enhancing it through additional prompts.

Development Workflow:

MVP → Enhancement → Refinement

---

## Initial MVP (NutriScope)

Using the provided Prompt 1, I generated the MVP version of **NutriScope**.

### MVP Features

* User Profile Inputs
* Food Logging
* Nutrition Tracking
* Macro Analysis
* Nutrition Recommendations
* Dashboard Visualizations
* Responsive Dark-Themed UI

The MVP provided a working nutrition tracker but had limitations in database size, analytics depth, meal planning, and user experience.

---

## Enhancement Process

After reviewing the MVP, I iteratively improved the application using enhanced prompts.

Instead of only applying the challenge Prompt 2, I expanded the scope by:

* Creating a structured nutrition dataset
* Expanding the food database
* Improving analytics capabilities
* Refining the UI/UX
* Enhancing responsiveness
* Adding planning and recommendation features

The final application became:

# 🥗 PoshBite

**Smart Nutrition. Better Choices.**

A nutrition analytics dashboard powered by a structured food database.

---

## Major Enhancements

### Nutrition Database

* Expanded from 20 foods to 60 Indian food items
* Created a CSV-based nutrition dataset
* Added macro and micronutrient information
* Improved food categorization and filtering

### Analytics & Insights

* Advanced nutrition tracking
* Micronutrient analysis
* Deficiency detection
* Risk analysis
* Improved dashboard insights

### User Experience

* Searchable food database
* Better food discovery workflow
* Enhanced recommendation system
* Improved responsiveness
* SaaS-inspired dashboard design

### Planning Features

* 2-Day Meal Planner
* Personalized food suggestions
* Data-driven nutrition recommendations

## Key Learning

The biggest takeaway from this challenge was:

> Building applications through multiple focused prompts produces significantly better results than attempting to generate a large application in a single prompt.

Following the workflow:

MVP → Enhancement → Refinement

resulted in a significantly better final product than generating everything at once.
