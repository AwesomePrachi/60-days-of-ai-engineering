# Day 16 – Build Your First Stock Research Skill

## Overview

Today I explored Claude Custom Skills and learned how to convert a long prompt into a reusable AI workflow.

Instead of repeatedly copying and pasting a large stock research prompt, I created a custom skill that can be reused across multiple conversations while maintaining a consistent analysis framework.

## Objective

The goal was to:

* Learn how Claude Custom Skills work
* Create a reusable workflow
* Eliminate repetitive prompting
* Generate consistent outputs
* Analyze companies using a structured framework

## What I Built

### Stock Fundamental Research Analyzer

A custom Claude Skill that converts a long research prompt into a reusable system for analyzing companies using a structured framework.

The skill evaluates:

* Business Analysis
* Financial Health
* Competitive Moat
* Risk Assessment
* Valuation Analysis
* Fundamental Scorecard

## Workflow

Repetitive Task → Structured Prompt → Custom Skill → Save Once → Reuse Anytime → Consistent Results

## Skill Test

To validate the skill, I performed a Deep Dive analysis of NVIDIA.

The generated report included:

* Business Overview
* Growth Analysis
* Financial Strength
* Competitive Advantages
* Risk Assessment
* Buffett Lens
* Fundamental Scorecard

## Key Insight

Most people use AI by repeatedly writing prompts.

Custom Skills allow you to create a process once and reuse it whenever needed, producing structured and consistent outputs with significantly less effort.

## Biggest Takeaway

Prompts solve a task.

Custom Skills solve a process.

Successfully created and tested a reusable Claude Custom Skill capable of generating structured stock research reports while reducing repetitive prompting.
