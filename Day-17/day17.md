# Day 17 – AI Vehicle Cost & Fuel Analysis Dashboard

## Challenge Objective

Build an AI-powered vehicle cost and fuel analysis dashboard by transforming a raw CSV dataset into an interactive business intelligence dashboard using Claude AI.

---

## Project Overview

For Day 17 of the 60 Day Claude Challenge, I used Claude AI to analyze a vehicle dataset and generate a complete HTML dashboard.

The dashboard converts raw data into meaningful insights by comparing fuel types, maintenance expenses, environmental impact, and long-term operating costs.

---

## Vehicle Configuration

* Vehicle: Tata Sierra EV
* Fuel Type: EV
* Usage Pattern: Mixed
* Monthly Distance: 1200 km
* Vehicle Age: 1 Year

---

## Features

### KPI Dashboard

* Cost per Kilometer
* Monthly Running Cost
* E85 Cost Comparison
* Running Cost Premium
* Break-even Analysis

### Data Visualizations

* Fuel Cost Comparison Chart
* CO₂ Emission Distribution
* Vehicle Age vs Running Cost Trend
* Maintenance Cost Analysis
* Refuel / Recharge Time Comparison
* E85 Composite Score Gauge

### Business Insights

* Fuel Efficiency Analysis
* Maintenance Cost Evaluation
* Environmental Impact Comparison
* Fuel Recommendation Engine

---

## Key Learning

This challenge demonstrated how AI can be used as a data analyst to transform structured CSV data into a professional dashboard without manually building calculations or visualizations.

I learned how to:

* Analyze structured datasets using AI
* Generate business KPIs from raw data
* Create dashboard-style visualizations
* Compare operational costs across fuel types
* Present insights through interactive reporting

---

## Outcome

Successfully generated a fully responsive Vehicle Cost & Fuel Analysis Dashboard using Claude AI and explored fuel economics, maintenance trends, emissions impact, and business intelligence reporting through data visualization.
