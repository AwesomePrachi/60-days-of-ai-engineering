# Day 10 – Personal Portfolio Website

## Challenge Objective

Build and deploy a personal portfolio website using Claude AI.

## What I Built

I created a modern personal portfolio website that showcases my:

* Skills & Technical Stack
* Featured Projects
* Experience
* Certifications
* Contact Information
* Social Links

The website was initially generated from a structured Claude prompt and then customized with improved design, responsiveness, content organization, and user experience enhancements.
