# Day 19 – Football Intelligence Hub

## Overview

For Day 19 of the 60 Day Claude Challenge, I built a Football Intelligence Hub using Claude AI. The project demonstrates how AI can analyze football data, generate tournament predictions, assess football knowledge, and create personalized personality profiles.

## Objective

The goal was to explore how AI can combine sports analytics, prediction systems, education, and personalization into a single interactive experience.

## What I Built

A Football Intelligence Hub capable of:

* Predicting FIFA World Cup 2026 outcomes
* Identifying tournament favorites and dark horses
* Highlighting players to watch
* Conducting a Football IQ assessment
* Calculating a Football Awareness Score
* Performing a Messi vs Ronaldo personality analysis
* Generating a personalized Football Intelligence Profile

## Key Learnings

* AI can identify patterns in sports datasets and generate evidence-based predictions.
* Interactive quizzes can be used to assess domain knowledge.
* Personality assessments can create highly personalized user experiences.
* AI can combine analytics, education, and entertainment within a single workflow.
