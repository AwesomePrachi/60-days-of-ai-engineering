# Day 6 – AI Resume Optimizer

## Objective

The objective of this task was to learn how AI can optimize resumes for Applicant Tracking Systems (ATS) and improve recruiter readability while keeping all information truthful and relevant.

---

## Tools Used

* Claude AI
* ATS Resume Optimizer Prompt
* GitHub

---

## Original Resume

Uploaded my existing resume and analyzed it using Claude's ATS Resume Optimizer.

### Key Characteristics

* Traditional resume structure
* No professional summary
* Limited ATS keyword optimization
* Generic action verbs
* Non-standard section organization

---

## ATS Analysis

### Previous ATS Score

**52/100**

### Optimized ATS Score

**83/100**

### Improvements Suggested

* Added a Professional Summary
* Enforced a Single-Column ATS-Friendly Layout
* Improved keyword density using relevant technical terms
* Replaced repetitive wording with stronger action verbs
* Reordered sections for ATS prioritization
* Standardized section headings
* Converted LinkedIn and GitHub references into ATS-readable text links

---

## Optimized Resume

Claude generated an ATS-friendly one-page resume with:

* Professional Summary
* Improved Skills Section
* Better Experience Descriptions
* Stronger Project Descriptions
* ATS-optimized Keywords
* Recruiter-Friendly Formatting

---

## Key Learnings

### 1. ATS-Friendly Formatting Matters

Complex layouts, icons, and multi-column designs can negatively impact ATS parsing.

### 2. Keywords Improve Discoverability

Including relevant technologies and concepts helps align resumes with job descriptions.

### 3. Strong Action Verbs Increase Impact

Using verbs such as "Architected", "Implemented", and "Developed" makes achievements clearer and more professional.

### 4. Professional Summaries Add Context

A concise summary helps recruiters quickly understand a candidate's profile.

### 5. AI Can Improve Presentation

AI cannot replace experience, but it can significantly improve how existing experience is presented.

## Conclusion

This exercise demonstrated how AI can be used to optimize resume structure, readability, and ATS compatibility without altering the authenticity of the content. Small improvements in formatting, keyword placement, and wording can significantly improve the effectiveness of a resume.
